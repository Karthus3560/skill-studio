# Changelog

## 2.0.0 — Skill Studio

- A brand-new, Claude-themed design: terracotta, cream and warm charcoal.
- A 48-icon **clay** icon set.
- A list layout in the side panel, and a responsive grid (2 to 4 per row) when the panel is wide.
- **Filter** menu and **⚙ Settings** menu that open over the list.
- A **details view** with the full description, Add to prompt, ↻ Rewrite, ✎ Edit and ☆ Favourite.
- **★ Favourites** and **Recent** sections.
- **Descriptions in English or Arabic**, both written once and cached.
- Skills are added **at the cursor**. Several per prompt work, and nothing you typed is lost.
- `/skill` names in the prompt are painted as clay chips.
- ↻ works even while a big description job is running.

## 1.x — Skill Picker

- The first version: a grid of skills with generated descriptions and the Cozy Neon icon set.
